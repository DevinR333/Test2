Holodrum 3D

Oracle of Seasons, rebuilt as one seamless voxel world from the oracles-disasm decomp.

Build the ROM with the decomp (make seasons) and pick it here.

Controls
MoveArrows / WASD
A / BX or K / Z or J
Start / SelectEnter / Shift
CameraDrag or Q/E (right stick on a gamepad) to orbit, wheel or pinch to zoom, C to reset
2D screenTab toggles the original screen
Save / load stateF5 / F9
